Infrastructure: Phishing

Setting up Phishing Infrastructure using nginx, gophish and terraform

Intro

Following my recent post about email security in the context of phishing: here is a guide on setting up phishing infrastructure using Gophish, nginx, Terraform, and Hetzner, a Germany-based hosting provider.

All the needed code is provided on my GitHub.

Prerequisites

  • Generate an SSH keypair: ssh-keygen -t ed25519
  • Create a Hetzner project: console.hetzner.com/projects
  • Generate an API key: console.hetzner.com/projects/<ID>/security
  • Grab your IP: curl -4 ifconfig.me

The server IP will be provided once terraform apply finishes.

journalctl will reveal the auto-generated credentials for the login.

Note: Gophish forces a password change on first login, so that initial password from journalctl is only good for the first sign-in.

On your machine

Now you’re able to visit the Gophish UI from your own machine at 127.0.0.1:3333.

What’s left to do?

  • Set up a domain + DNS and point it to your server IP
  • Provision TLS using Let’s Encrypt or anything else
  • Set up SPF/DKIM/DMARC on the sending domain, pointed at the Gophish sending profile
  • Create a campaign
  • (Optional, for red team engagements) Include Evilginx
